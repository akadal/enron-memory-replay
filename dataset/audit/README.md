# Reviews and decisions

The files here are dated records, kept as they were written: the plan review and design
consultation before the run, the design decision, the pilot review, the model checks, and the
reviews at the run's holds (after slices 30, 60, 90, 90 again and 120). Each run review ends
with what the main session checked and applied. Where a record and `dataset/DESIGN.md` differ,
`DESIGN.md` describes what actually ran.

Some records plan things that v1.0.0 does not have: an `eval/` folder, a recall probe, a join
with EnronQA, `DATASHEET.md`, `dataset/PLAN.md`, `dataset/README.md`, capture
by Claude Haiku 5.5 over OpenRouter, and a second mailbox. None of them is part of this release;
the README's sections on preparation, use and limitations take the place of a datasheet.
