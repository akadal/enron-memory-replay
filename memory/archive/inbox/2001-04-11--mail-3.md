(mail · received · m06770 · automatic capture)
From: Stinson Gibner <Stinson Gibner/HOU/ECT@ECT> · Subject: P+ option valuation model

- Stinson Gibner (V.P. Research) reviewed the booking of the P+ options and told Mark Fondren (cc the owner, Scott Earnest) on 2001-04-11 that they are valued with a standard two-commodity spread option model: correlated GBM legs, Black-76 assumptions extended to two commodities.
- P+ call option payoff per Stinson Gibner: Max(0, A - B - K), where A = NXWTI (Nymex delivery price), B = Posting Price = WTI Swap minus Posting Basis, K = Posting Bonus (fixed).
- Stinson Gibner noted that leg B of the P+ spread combines three prices (the two futures making up the month's WTI swap plus the average posting basis); this is handled by setting leg B's volatility and its correlation with NXWTI for the basket.
- Stinson Gibner prefers the two-leg basket approach for P+ options over a three- or four-commodity model with its volatility and correlation matrices, calling it more straightforward.
- Stinson Gibner concluded the spread option model is appropriate for valuing the P+ options, provided the inputs are set correctly.

- The owner's position on VaR: the curves for the biggest 10-20 positions in each commodity should be modeled as core curves, with no mapping into other locations, so the biggest risks are monitored separately. (owner, verbatim: "The curves associated with the biggest 10-20 positions in each commodity should be")
- The owner's position on VaR: a human should systematically monitor the results of automated clustering (mapping) of curves and correct them if they misrepresent trading-position risks. One person should hold this responsibility. (owner, verbatim: "This responsibility should be vested with one person")
