## 02:07

(mail · received · m05120 · automatic capture)
From: Zimin Lu · Subject: Option hedging for EES

- Zimin Lu and Bob Lee discussed a question raised by Eugene Zeitz about hedging options for EES; Zimin replied to Eugene with the owner and Stinson Gibner copied.
- Zimin Lu's view: an option writer should delta-hedge with the underlying (hedging cost theoretically equals fair premium), but an option holder should not delta-hedge, as he would pay double with no upside.
- Zimin Lu advised that an option holder wanting to protect time value should sell the option or equivalent options to create a theta-neutral portfolio, possibly trading both underlyings.
- Zimin Lu questioned Eugene Zeitz on whether call options embedded in EES contracts (e.g. fixed price sale contracts) can be separated and sold; Zimin conjectures they hedge the original contract, and selling them removes its upside.
