(mail · sent · m08962 · automatic capture)
From: Kaminski, Vince J </O=ENRON/OU=NA/CN=RECIPIENTS/CN=VKAMINS> · Subject: FW: HJM forward curve modeling

- On Aug 16, 2001 Zimin Lu sent Tom Halliburton a C routine (HJMsim), the HJM forward curve modeling module of the storage model. Lu asked him to study it, especially the blue section, and then meet to discuss using it in Tom's optimization model.
- The storage model's HJMsim routine simulates the forward curve with an n-factor HJM model. Current factor loadings come from historical factor loadings via a historical correlation matrix and forward volatilities. It steps weekly (freq=4) or daily (freq=30).
- In the storage model, simulated spot equals the interpolated prompt forward plus a mean-reverting spread. The spread is correlated with the prompt factor and labeled a 'new price process 11/99'. The routine uses convergence theory to set the starting forward.
- The storage model's HJMsim routine bins each simulated state on two variables, spot and the prompt-minus-spot spread. It accumulates per-bin counts, spot and prompt sums, and populates a transition probability matrix between time steps.
- The owner forwarded Zimin Lu's HJM forward curve modeling memo and code to his personal AOL address (vkaminski@aol.com) on 2001-08-16.
