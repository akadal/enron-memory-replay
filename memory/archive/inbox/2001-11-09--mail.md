From: Issler, Paulo </O=ENRON/OU=NA/CN=RECIPIENTS/CN=PFISSLE> · Subject: HJM simulation

- Paulo Issler sent the owner and research colleagues (Alex Huang, Bob Lee, Krishnarao Pinnamaneni, Tanya Tamarchenko, Vasant Shanbhogue, Zimin Lu) C code for an HJM simulation model for option pricing, asking for opinions and bug reports.
- Paulo Issler's HJM model takes prices and volatilities as inputs and generates a daily spot price grid with transition probabilities; it handles fwd-fwd vols, uses different PCA factor loadings for each month, and allows as many factors as forward curve points.
- In Paulo Issler's HJM model, the expected next-day spot is linearly interpolated with the prompt fwd so spot converges to prompt month price near month end; this makes spot vol converge to prompt month vol.
- Paulo Issler put the self-contained HJM project at o:\research\common\project\options\HJM (files HJMsim.c, HJM.c, Support.c, NRC.c, NRUTIL.c); the fwd-fwd vol and loading factor functions for the example spreadsheet are in o:\research\custom.
