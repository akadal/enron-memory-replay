# CrudeAPO Asian option model and its documentation, May 2001

- [2001-05-02] Zimin Lu sends Tai Woo (cc Kara Maloney; reviewing how Pavel's model differs from the standard one) the C code of CrudeAPO, which Pavel Zadorozhny values his Asian option portfolio with: 'Sig' is the spot volatility within the delivery period; ask Pavel about the extra parameters; show Research the Position Monitor once it runs. He asks Paulo Issler why it has no documentation and is missing from the Exotica help file. ←[[m07519]]
- [2001-05-02] Issler: Zimin never documented it and his own changes left the function alone; he offers to write it. Zimin: whoever finalises a model documents it; Paulo has worked on it almost a year; Zimin created Exotica.xll, which excuses no one. ←[[m07522]]
- [2001-05-02] Zimin asks the owner how to handle team members who refuse projects or duties, citing Issler and an El Paso candidate who seemed above some projects. ←[[m07524]]
