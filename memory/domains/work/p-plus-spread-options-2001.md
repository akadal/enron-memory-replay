# Koch P+ spread options book: correlation review (Jan 2001)

Detail ←[[p-plus-spread-options-2001-2001-04-w16]] ←[[p-plus-spread-options-2001-2001-06-09]]

Desk analysis generally: memory/domains/work/desk-analysis-requests.md.

- [2001-04-11] Gibner to Mark Fondren (cc Scott Earnest, owner) after reviewing the booking: P+ options use a two-commodity spread option model (correlated GBM, Black-76 extended); call payoff Max(0, A - B - K), A = NXWTI, B = WTI swap minus posting basis (a basket, handled through leg B's vol and correlation), K = posting bonus; simpler than a 3-4 commodity model and appropriate if inputs are set right. ←[[m06734]] ←[[m06770]]
- [2001-04-19] Gibner (cc owner) builds the new P+ model Jeffrey Shankman asked for, after Spencer Vosko's needs and posting-vs-Nymex history: not Monte Carlo (recalculation time) but the spread model with one leg a basket (Nymex swap plus posting basis = posting price); function ready, test book for P&L impact next with Vosko and Fondren; value change looks small. ←[[m06985]]
- [2001-06-06] Gibner's P Plus pricing model and documentation (an early draft that still needs revision, explaining the spread option structure) go to the owner via Zimin Lu; owner copies them to AOL 6-7 Jun. ←[[m08408]] ←[[m08410]] ←[[m08415]] ←[[m08448]]
