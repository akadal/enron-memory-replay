# Henwood Prosym license

- [2000-01-12] [[grant-masson]] told Karla Feldman (Heather Mitchell copied) that Enron renews the Prosym software modules but not the North American database licenses, and asked her to start the amendment process asap (Masson wrote it, not the owner). ←[[m00328]]
- [2000-01-12] Modules renewed: Base System (ECOsym included), ASAP/MSTAT, MULTISYM and the EMSS interface, which may not be needed. ←[[m00328]]
