# Clayton Vernon's gas flow/price model

Clayton Vernon works on it with Vasant Shanbhogue. ←[[m00042]]

- [1999-12-15] Proposal: from interconnect flows and spot prices, detect capacity hoarding, market power and storage (exotic calls at the consumption hub) → a stochastic basis model in weather. ←[[m00025]]
- [1999-12-16] Chris Germany (East Desk): firm capacity is a fixed monthly lease; variable 6% fuel + 6.5% overhead; willingness to pay = delivered spread minus variable cost. ←[[m00042]]
- [1999-12-22] Simplified version of Brad's model: no-arbitrage margins, congestion raises transmission cost, storage a perpetual call; 8 parameters per node from 3 days' prices; write-up, then a presentation. ←[[m00086]]
- [1999-12-27] Roy Kass (EIA): wellhead estimates not timely; field weather moves production more than Northeast weather; agrees on strictly increasing marginal production cost. ←[[m00102]]
- [2000-01-06] Vernon: Operational Balancing Agreements mean shippers book scheduled, not actual, flows; producing-region storage protects the system; marketed production is the better proxy for receipt-meter flow. ←[[m00172]]
- [2000-01-17] Basis "uncoupling": Midwest cold can lift Henry Hub so Northeast basis falls below the cost of shipping, as spot gas stops flowing along every node. Owner: "This would happen when there is an insufficient pipeline capacity to move gas ... one of the reasons we want to have the model you are working on." ←[[m00353]]
