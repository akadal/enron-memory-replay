## 04:59

(mail · received · m06411 · automatic capture)
From: Rakesh Bharati · Subject: Comments

- Rakesh Bharati and Vasant Shanbhogue reviewed a memo by Sheridan (Titman, UT Austin) proposing a state-space/simulation project valuation method with endogenously determined discount rate and risk capital; Rakesh sent comments, cc the owner.
- Rakesh Bharati told Sheridan that setting aside risk-free bonds for every negative node realization could make risk capital extremely high, since the method no longer follows a tail-based norm.
- Rakesh Bharati questioned whether Sheridan's iteration on the discount rate (matching variance to a comparable investment) converges globally, and how to define variance given finite project life vs infinite-lived market assets.
- Rakesh Bharati noted Sheridan's memo implies debt capacity only if all node values are positive, i.e. only risk-free debt would be issued.
- Rakesh Bharati proposed a gas field test case for Sheridan's model: x million investment, engineer-provided production profile and variance, autocorrelated production, 10-year life, no salvage value, fixed and variable operating costs.

## 11:47

(mail · received · m06412 · automatic capture)
From: Rakesh Bharati · Subject: Re: Comments

- Rakesh Bharati forwarded to the owner and Vasant Shanbhogue Sheridan Titman's (UT Austin) replies on his risk capital/discount rate methodology; Titman says his approach is a conservative initial estimate needing refinement.
- Titman proposed setting risk capital so project PV is positive at each node (or e.g. 98% of nodes), and defining debt capacity so the project defaults a certain percent of the time.
- Titman said the discount rate iteration needs only one pass if project volatility is independent of the discount rate; the finite-life vs. infinite-life comparison asset variance issue needs more thought.
- For the gas field test case, Titman suggested valuing it by comparing the developed project's volatility to a traded comparison (e.g. an MLP) and using its risk-adjusted return as the discount rate.
- Titman asked Rakesh for data on a case where Enron bought/sold a base load power plant financed with non-recourse debt (price, debt terms, gas-power swap/option pricing) to test his project debt pricing model, which he gave the owner about a year ago.
