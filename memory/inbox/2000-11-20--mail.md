## 02:57

(mail · received · m04312 · automatic capture)
From: Tanya Tamarchenko · Subject: Re: smoothing methodology for extracting forward forward volatilities

- Tanya Tamarchenko ran a smoothing procedure on the R8 forward volatility curve (effective Nov. 8, 00): fit each of 12 monthly forward vol curves with a+A*(t+B)^(-beta), bootstrap forward-forward vols from each fit, then reconstruct the ff vol curve.
- Tanya Tamarchenko asked the group (Naveen Andrews, Alex Huang, Vince Kaminski, Vasant Shanbhogue, Ted Murphy, Vladimir Gorny, others) whether more results are needed before implementing the ff vol smoothing in the test environment.
- Tanya Tamarchenko found that for the function class a+b*exp(-tc), the bootstrapping procedure is guaranteed to work only if a/b > 2*exp(-1.5); she suggested this class could also be used.
- Naveen Andrews reported that exponential fits (a+b*exp(-cx)) fit well but gave negative ff vols in bootstrapping, while the power law a+b(t+c)^(-1) fit the 12 months well without negatives; he prefers exp(-t) for mean-reverting vols but sees the power law as practical.
- Tanya Tamarchenko noted Naveen's power law a+b(t+c)^(-1) corresponds to her beta=1, and argued any chosen function class needs specified parameter ranges that guarantee the ff vol bootstrapping works.
