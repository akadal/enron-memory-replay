## 12:29

(mail · received · m09218 · automatic capture)
From: Halliburton, Tom </O=ENRON/OU=NA/CN=RECIPIENTS/CN=THALLIB> · Subject: ModReg for Argentina

- Tom Halliburton reported that Enron models Argentina with ModReg, a Fortran model by Buenos Aires consultants (modified grid-operator model), needing a CPLEX licence; Spanish-only docs, column-oriented text-file input, no source code or algorithm documentation.
- Per Tom Halliburton, ModReg uses a weekly time step, five load blocks per week, typically a one-year horizon, about 30 busses and 71 lines; each run takes about 6 hours; hydro generation schedules are input, calculated elsewhere.
- Tom Halliburton judged the ModReg situation unsatisfactory (hard to use, undocumented, fully dependent on consultants) and said Enron should not use a consultant-built model without documentation; a GUI is needed.
- Tom Halliburton proposed SDDP as a likely ModReg replacement for Argentina: needs reservoir inflow data, DC loadflow with zero-impedance lines, guessed line resistances for quadratic losses; setup would be time consuming but gives docs, GUI, flexible output.
- Tom Halliburton sent his ModReg comments (2001-09-28) to Jorge Gumucio, M. Rosenberg and Remi Collonges, copying the owner and Zimin Lu.
