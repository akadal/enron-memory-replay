(mail · received · m03333 · automatic capture)
From: Naveen Andrews · Subject: Update: FFVols

- Naveen Andrews told Ted Murphy (cc the owner) that for Agg-Gas, historical VaR ran consistently about 17MM below implied-vol VaR over 6 days; for effective date 09/25 historical VaR was 19.2MM vs implied 37MM, as implied vols anticipate strong winter prices.
- Naveen Andrews reported the consensus is not to release the historical-vol (FFVols) VaR implementation into production; the official line to traders is that the method is still in testing.
- Naveen Andrews said a hybrid VaR methodology is being tested: historical vols scaled by the ratio of prompt to historical-prompt volatilities, to capture some implied/forward effects.
- Per Naveen Andrews, Tanya's analysis on a fictitious portfolio showed the hybrid-vol approach gives higher VaR but poorer backtesting than the historical approach; seen as an intermediate suited to periods when historical is well below implied.
- Naveen Andrews said Winston will start testing with the hybrid vols, and if results are satisfactory that will become the production VaR methodology; all VaR numbers will still be computed concurrently as risk indicators.
