## 03:54

(mail · received · m02448 · automatic capture)
From: Stinson Gibner · Subject: Credit Support Value for MG and PaperCo

- Stinson Gibner sent Amitava Dhar, Paulo Issler and Tanya Tamarchenko (cc the owner) a spreadsheet with his very rough calculation of the value of credit support for MG and PaperCo, asking for comments.
- Stinson Gibner's credit support method: model all MG/PaperCo contracts as financial swaps and spread notional trading volumes over estimated swap tenors.
- Stinson Gibner values the default option at each swap period using Black's formula, then treats these values as a risky annuity-like cash flow stream.
- Stinson Gibner computes the value of credit enhancement as the difference between NPVs of the default-option stream discounted at the original risky rate and at the risk-reduced rate.
