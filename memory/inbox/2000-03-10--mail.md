From: Martina Angelova · Subject: New Update on PPI Model for Inflation Book - Final Version

- Martina Angelova told the owner that the UK Inflation Book's main exposure is to two PPI Output indexes, PLLU and DZCV, through year 2010; the only significant difference is energy in the PLLU (7.6%), yet the model in use escalates both by the same factors.
- Anjam Ahmad proposed, as the final UK PPI PLLU model for the Inflation Book: PLLU[t] = a.RPI[t] + b.RPI[t+15] + c.BrentCrudeDeviations[t] + Constant, with Brent deviations from a long-term average of $18.80 (Global Products Group Brent forward curve used for predictions).
- Martina Angelova said the new PLLU model is significantly more robust and stable than the existing one and less sensitive to input coefficients, giving more confidence in monthly P&L and fewer fluctuations.
- Anjam Ahmad will shortly build a separate model for the DZCV PPI index using the same methodology but without the Brent Crude curve.
- Anjam Ahmad reported the Brent-inclusive PLLU equations had r-squared approx 0.49 and F-stat approx 32 (vs 0.47 / 45 for RPI-only); dropping 1990 data collapsed fit, and a sine-wave test showed PPI leads RPI moves by about 8 months.
